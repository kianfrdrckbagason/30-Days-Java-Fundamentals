Today, I learned about **patterns using nested `for` loops** and how the outer and inner loops can represent **rows and columns** when creating different patterns. I created a **right triangle pattern** by controlling the number of stars printed on each row, and I also created a **reverse pattern** by changing the loop conditions to decrease the number of stars on each row. This helped me understand how changing the starting point, condition, and increment or decrement of a loop can control the shape and direction of a pattern.
