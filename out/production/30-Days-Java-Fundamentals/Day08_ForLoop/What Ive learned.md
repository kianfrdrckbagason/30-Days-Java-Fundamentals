Today, I learned about the `for` loop in Java and how it can be used to repeat a block of code based on a specific condition. I learned the three main parts of a `for` loop: initialization, condition, and increment. I also applied the modulo operator `%` that I learned from Day 2 to determine whether a number is even by checking if the remainder is equal to `0`. Through this practice, I learned how to combine loops, conditions, user input, and operators to create a simple program that prints even numbers within a given range.
