Today, I learned about the `do-while` loop, including its syntax and how it differs from a regular `while` loop by executing the code at least once before checking the condition. I also applied nested situations by combining `while`, `switch`, `if`, and `do-while` statements to create a simple signup and login system. I learned how to compare values such as usernames and passwords using `.equals()` and how to apply logical operators like `&&`, `||`, and `!` when creating conditions. I also improved my understanding of the boolean datatype by using it to represent whether an account has been created, and I learned how to simplify conditions to make my code more readable and logically correct.
